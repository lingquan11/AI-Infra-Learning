Code repository for [ai-infra-plan](https://github.com/lingquan11/ai-infra-plan): labs, notes and performance logs.

[ai-infra-plan](https://github.com/lingquan11/ai-infra-plan)（36 周 AI Infra 学习计划）的主线代码仓库。学习路线、每周任务和成果展示都在 ai-infra-plan，这里只放代码、笔记和性能日志。

## 目录

| 路径 | 内容 |
|---|---|
| `labs/` | 每周的实践代码 |
| `notes/` | 笔记 |
| `perf-log.md` | 性能日志：日期 \| 改动 \| 硬件 \| tokens/s \| 显存峰值 \| MFU \| 备注 |

ai-infra-plan 的成果展示引用代码时，链接到本仓库的具体 commit。
